# 家庭组网笔记

## 五层模型

| 层   | 名称       |       常见功能应用        |
| ---- | ---------- | :-----------------------: |
| 5    | 应用层     |      HTTP、DNS、DHCP      |
| 4    | 传输层     |         TCP、UDP          |
| 3    | 网络层     |   IP、路由器、网关、NAT   |
| 2    | 数据链路层 |  以太网、交换机、AP、MAC  |
| 1    | 物理层     | 光纤、网线、WiFi 无线电波 |

分层和包装的大概过程如下：

1. 数据
2. TCP Segment（+TCP头）
3. IP Packet （+IP头）
4. 以太网帧 Frame（+以太网头+帧尾）
5. 物理信号010100100101001

因为路由器，网关，NAT管理的数据对象都是IP Packet，所以属于网络层

因为交换机，AP，MAC管理的数据对象都是以太网帧，所以属于数据链路层

## 经典家庭拓扑

### 总体拓扑图

```text
互联网
  │
运营商网络
  │
入户光纤
  │
光猫
  │
路由器
  │
  ├── 交换机 → 有线设备
  └── AP → WiFi → 无线设备
```

### 一、入户光纤

​	光纤是传输 **光信号**的物理介质，上游接的是运营商网络，下游接的是光猫设备

### 二、光猫

​	光猫，也叫 ONT / ONU，最核心功能是 **光信号-电信号**转换，接口有光纤接口，LAN接口

​	光猫存在以下两种模式

|   模式   |                       核心区别                        |
| :------: | :---------------------------------------------------: |
| 桥接模式 |    只做光电转换，拨号、NAT、 DHCP 等功能交给路由器    |
| 路由模式 | 除了光电转换外还可以拨号、NAT、DHCP，是家庭网络的网关 |

### 三、拨号

​	拨号的意思是向运营商发起一个接入会话，填入宽带账号密码认证通过后拿到一个 WAN 侧 IP，才能上网

### 四、NAT

​	NAT的全称是Network Address Translation，是一种**地址转换机制**，作用是修改**IP数据包**的源地址，目的地址，TCP/UDP端口等等，也就是常用的把IPv4 公网地址与私有地址 双向转换

### 五、网关

​	网关 Gateway 是连接两个不同网络的**设备**，有自己的IP地址，负责把**IP数据包**从一个网络传输到另一个网络。比如`ip r`展示的就是路由网关ip 地址。

​	网关是一种抽象角色，具体点的，可以是路由器，也可以是光猫

### 六、路由器

​	路由器**作用是把IP数据包从一个网络转发到另一个网络**。

​	**接口**

- 一个WAN 口（World Area Network）：朝外，接光猫

- 多个LAN 口（Local Area Network）：朝内，接电脑、交换机、AP

​	**核心功能**

- 路由转发
- 拨号（PPPoE）
- NAT
- DHCP

> DHCP（Dynamic Host Configuration Protocol）除了自动分配IP地址外还会分配DNS服务器地址，默认网关等
>
> **谁做拨号、NAT、DHCP，谁就是家庭网络中心。**

### 七、交换机

​	交换机上游接路由器 LAN 口，下游接多台有线设备。

​	作用是在**同一局域网**内部拓展**有线网口**（**注意和AP区分**，AP是拓展无线接入网口），但是转发的是以太网帧，也就是说DHCP等功能还是由家庭网络中心完成（路由器或者光猫）。所以工作在数据链路层。

### 八、AP

​	AP（Access Point）也叫无线接入点，是一个具体的物理设备。作用是把有线网络变成 WiFi 信号，让无线设备接入。

​	上游接路由器 LAN 口或交换机，下游通过 WiFi 连接手机、电脑。它与交换机属于一类东西，也不做 DHCP等功能

### 九、Wi-Fi

​	Wi-Fi 是一种基于IEEE 802.11标准的无线局域网技术，而AP 是发射 WiFi、让设备接入的设备



> WLAN vs Wi-Fi vs AP
>
> WLAN（Wireless Local Area Network），是一种无线局域网
>
> Wi-Fi是一种无线局域网技术，是WLAN的一种实现。这两种说法常被混淆
>
> AP是发射Wi-Fi的设备



## FTTR 特例

### FTTR 拓扑图

```text
互联网
  │
运营商网络
  │
入户光纤
  │
主光猫（光猫 + 路由器）
  │
├── 子光猫 1（AP + 交换机）→ 房间 WiFi / 网口
├── 子光猫 2（AP + 交换机）→ 房间 WiFi / 网口
└── 子光猫 3（AP + 交换机）→ 房间 WiFi / 网口
```

### 主光猫（家庭网络中心）

**角色**：光猫 + 路由器。

**功能**：拨号、NAT、DHCP、默认网关。

### 子光猫

**角色**：AP + 交换机。

**功能**：扩展 WiFi 和网口，把主光猫的网络延伸到房间。

> 默认不需要额外路由器，加路由器是为了：桥接替换、旁路由、二级路由、提升 WiFi、折腾 OpenWrt 等
